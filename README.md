# Bobby Carrot (Web Version + C++ Solver)

在Gemini3.0的辅助下，基于HTML5/CSS3/JavaScript复刻了经典的《Bobby Carrot 1》。本项目不依赖任何第三方库，支持关卡解析、回放系统、存档管理以及自动寻找最优解。

## 🌏 在线试玩
https://4454aa.github.io/BobbyCarrot1_html_version/

## 📂 项目目录结构

本项目包含前端游戏与后端求解器两部分，目录结构如下：

```text
BobbyGame/

├── css/
```

```text

'>' = Belt_Right (向右传送带)
```

## 🎮 详细游戏规则

玩家控制角色 **Bobby**（从 `@` 处出生），目标是**收集所有胡萝卜 (`*`)** 并 **填满所有彩蛋坑 (`e`)**，最后抵达终点 (`o`)。

### 1. 基础移动与地形
*   **操作**: 使用 `WASD` 或 `方向键` 移动。
*   **边界**: 地图边缘不可逾越。
*   **草地 (`.`) / 栅栏 (`=`) / 已种彩蛋 (`E`)**: 均为障碍物，不可进入。
*   **空地 (` `)**: 自由通行。

### 2. 收集与陷阱
*   **胡萝卜 (`*`)**: 进入后计数+1，该位置变为空地 (` `)。
*   **陷阱 (`x` / `X`)**:
    *   **未激活 (`x`)**: 安全进入。但当玩家**离开**此格子后，它会变为 **已激活陷阱 (`X`)**。
    *   **已激活 (`X`)**: 如果踩入此格子，游戏结束 (Game Over)。

### 3. 传送带机制 (`<`, `>`, `^`, `v`)
*   进入传送带后，角色会被强制向箭头方向传送。
*   **连续传送**: 角色会沿着连续的传送带一直滑动，直到遇到非同向传送带、障碍物或地图边界。
*   **阻挡**: 如果传送带末端被阻挡（如墙壁），角色将停留在传送带的最后一格。此时只能尝试向垂直于传送带的方向移动离开。

### 4. 动态墙壁 (Post-Move Rotation)
此类机关在玩家**完全离开**格子后触发变形。

*   **竖翻转墙 (`|`)**: 仅允许从**上方**或**下方**进入。离开后，变为 **横翻转墙 (`-`)**。
*   **横翻转墙 (`-`)**: 仅允许从**左侧**或**右侧**进入。离开后，变为 **竖翻转墙 (`|`)**。

### 5. 旋转转角 (Corner Pipes)
转角管子具有严格的通行规则，且在玩家**离开**后顺时针旋转 90°。

*   **`⌝` (连接左与下)**:
    *   允许: 左进下出 / 下进左出。
    *   离开后变身: `⌟`
*   **`⌟` (连接左与上)**:
    *   允许: 左进上出 / 上进左出。
    *   离开后变身: `⌞`
*   **`⌞` (连接右与上)**:
    *   允许: 右进上出 / 上进右出。
    *   离开后变身: `⌜`
*   **`⌜` (连接右与下)**:
    *   允许: 右进下出 / 下进右出。
    *   离开后变身: `⌝`

### 6. 全局开关按钮
*   **红按钮 (`R`)**:
    *   进入后，地图上**所有**的 `R` 变为 `r`，`r` 变为 `R`。
    *   同时，地图上**所有**的 **转角 (`⌝` `⌟` `⌞` `⌜`)** 和 **翻转墙 (`|` `-`)** 均顺时针旋转 90°。
    *   `r` 为已按下状态，踩上去无反应。
*   **黄按钮 (`Y`)**:
    *   进入后，地图上**所有**的 `Y` 变为 `y`，`y` 变为 `Y`。
    *   同时，反转所有传送带方向（`^` ↔ `v`，`<` ↔ `>`）。
    *   `y` 为已按下状态，踩上去无反应。

### 7. 钥匙与锁
*   **钥匙 (`s`, `g`, `c`)**: 进入即拾取，变为地面。拾取后永久持有。
*   **锁 (`S`, `G`, `C`)**: 只有持有对应颜色的钥匙才能进入。进入后锁消失（变为地面）。

### 8. 彩蛋机制
*   **彩蛋坑 (`e`)**: 可以直接进入。
*   **播种**: 当玩家**离开**彩蛋坑时，该位置变为 **彩蛋 (`E`)**。
*   `E` 视为障碍物，无法再次进入。

### 🏆 胜利条件
同时满足以下三点，并踩上终点 (`o`)：
1.  胡萝卜收集数量 = 关卡总胡萝卜数。
2.  已播种彩蛋数量 = 关卡总彩蛋坑数。
3.  当前位置为终点。

## 🚀 C++ 求解器 (CppSolver)

为了解决复杂的关卡并寻找最优步数，本项目包含一个基于 C++17 编写的 A* 求解器。

### 1. 功能特性
*   **智能解析**: 直接读取 `../js/levels.js`，无需手动转换数据格式。
*   **加权 A\***: 支持调整启发式权重，在“寻找最短解”与“快速求解”之间取得平衡。
*   **可达性剪枝**: 内置 BFS 泛洪填充算法，自动识别并剪除死局（Deadlocks），解决复杂陷阱关卡。
*   **自动导出**: 解出的路径会自动写入 `../js/solutions.js`，Web 端可直接读取演示。

### 2. 编译指南 (Windows/Linux)

请确保已安装 `g++` 编译器 (推荐 MinGW-w64 或 Linux GCC)。

打开终端进入 `CppSolver` 目录，执行以下命令：

```bash
g++ -O3 -std=c++17 src/main.cpp src/Solver.cpp -o solver.exe
```

### 3. 运行与参数

编译成功后，直接运行生成的程序：

```bash
.\solver.exe
```

程序启动后会询问以下参数（直接回车可使用默认值）：

1.  **Weighted A* Weight** (默认 1.0):
    *   `1.0`: 寻找理论最优解（步数最少），速度较慢。
    *   `3.0` - `5.0`: 牺牲少量步数优势，换取极快的搜索速度（推荐用于长关卡）。
2.  **Max Nodes Limit** (默认 2,000,000):
    *   搜索节点上限。如果内存足够（如 16GB+），可开到 `20000000` (2千万) 以解决极难关卡。
3.  **Use Reachability Pruning** (默认 0/No):
    *   `0`: 关闭。速度快，适合大多数关卡。
    *   `1`: 开启。每次移动都会进行死局检测，搜索速度变慢，但能解开包含复杂单行道陷阱的关卡。

### 4. 结果应用

运行结束后，程序会在 `js/` 目录下生成 `solutions.js`。
刷新网页版游戏，在选关界面如果看到关卡卡片上出现 **"▶ 回放解法"** 按钮，说明该关卡的解法已被成功加载。

## 💻 Web 端核心逻辑 (js/game.js)

*   **`tryMove(dx, dy)`**: 处理移动状态机，包含预判、执行移动、后结算（Post-Move Effects）和交互。
*   **`handleBelts()`**: 递归处理传送带动画，支持 `isAnimating` 锁防止输入冲突。
*   **`canExitCorner / canEnterCorner`**: 实现了严格的管道接口匹配逻辑，支持原路返回检测。
*   **`saveRecord`**: 自动记录并持久化玩家的最优成绩。
